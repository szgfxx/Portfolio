# Gallery photos

Drop photos here and they show up on the gallery page (photos.html) by themselves,
usually within 2 minutes. GitHub shrinks them for the web, so full-size phone photos
(including iPhone .HEIC) are fine.

**To upload on github.com:** open this folder → **Add file** → **Upload files** → drag
photos in → **Commit changes**.

## The filename is the label

```
2025-08 Morse theory summer -- TA'ing topology in Şirince.jpg
^date   ^title                 ^caption (optional, after " -- ")
```

- **Date** (optional): `2025`, `2025-08` or `2025-08-14` at the start. Photos sort newest first.
- **Categories:** put photos in a sub-folder (`travel/`, `research/`, `Nepal/`…) and each
  folder becomes a filter button. To make a new folder while uploading, drag a whole
  folder in from your computer.
- Rename or delete a photo here and the gallery follows.
- Want a longer description? Add a line to `album` in `js/content.js` (instructions there).
